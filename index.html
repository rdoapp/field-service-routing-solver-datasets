Why these datasets

Classic routing benchmarks are clean and well studied, but they leave out much of what makes a field-service day hard. These problems keep it in.

Heavy over-demand

The queue holds several times more work than the fleet can serve. Choosing what to serve is most of the problem.

Skills with counts

Installations need two qualified installers, so only a two-person crew can take them.

Breaks that stop travel

No driving or service may overlap a technician's lunch break.

Windows and priorities

Jobs can have one or two time windows, a priority from 1 to 3, and required skills.

Real road networks

Travel times and distances come from OpenStreetMap, routed with OSRM. No straight-line distances.

Checkable results

Upper bounds, best known solutions, and a validator and scorer that need only Python.

Datasets

Each dataset is a fixed, versioned, checksummed release. Problems never change within a major version, so results stay comparable.

HVAC field-service days v1.1.0 60 instances

One working day of an air-conditioning service company in Budapest and Pécs, Hungary. It cleans, washes, installs and repairs units. The question each problem asks: which jobs does each team serve, in which order and when?

  • Objective, in order: most service minutes, then most urgent minutes, then least travel.
  • full instances: a backlog of 462–1 350 jobs, for ranking solvers.
  • servable instances: one known plan serves the whole queue, for testing and debugging.
  • Synthetic: no real customer, address or company.

Quick start

The tools need Python 3.9 or later and nothing else.

git clone https://github.com/rdoapp/field-service-routing-solver-datasets.git
cd field-service-routing-solver-datasets/hvac

sha256sum -c SHA256SUMS            # verify every file

# check a solution against every rule of PROBLEM.md
python tools/validate.py problems/budapest-t05-servable-s4/problem.json \
    tools/example/example-solution.json

# score your solution against the best known one
python tools/score.py problems/budapest-t05-servable-s4/problem.json \
    problems/budapest-t05-servable-s4/durations_s.csv.gz \
    problems/budapest-t05-servable-s4/distances_m.csv.gz \
    my-solution.json solutions/budapest-t05-servable-s4/rdo.json

Found a better solution? Open an issue or a pull request with the solution file. It is validated, ranked, and added under its own id, credited to you.
